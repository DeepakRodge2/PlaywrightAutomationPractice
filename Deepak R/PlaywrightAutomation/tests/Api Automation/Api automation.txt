1.Rest API
   -Rest Support  JSON as Input
   -when we talk about web app and mobile app generally application developer use REST API
   -Rest apis are lightweight is does not contain any cache
2.SOAP API
    -API support XML,JSON, and normal text as an input value

there are three level of appication developement
1.presentaion layer:-is the part of an application that the user sees and interacts with. It is also called the UI (User Interface) Layer.

2.buisness layer:-what is busness layer
Business Layer is the part of an application that contains the application's business logic and rules. It decides how the application should work based on the requirements.

3.database layer:-database Layer is the part of an application responsible for storing, retrieving, updating, and deleting data in a database. It is also called the Data Layer.
